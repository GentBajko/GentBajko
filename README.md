### Products

| | | Status | |
| :-- | :-- | :-- | :-- |
| **BusinessDone** | Scanned PDFs become searchable documents. The text layer goes on top of the page you already trust — OCR output never touches the original image. | Shipping | [businessdone.tech](https://businessdone.tech) |
| **Slopify** | Prompt → research → article → narration → images → MP4. Runs on your machine with your own provider keys, and shows the cost before every call. | Live on npm | `npx @gentbajko/slopify@latest` |
| **Capstone** | Architecture docs your coding agent reads instead of re-exploring the repo every session. Stamped to commits, refreshed only where the code moved. | Open source | [repo](https://github.com/GentBajko/capstone) |
| **Quarry** | Every repo's Capstone reference in one index, answering the cross-repo question: who consumes what this repo produces, and what breaks if it changes. One static binary, no model, no service. | Open source | [repo](https://github.com/GentBajko/quarry) |
| **Clippa** | A stream ends, the VOD is processed, and long-form videos and vertical clips are prepared for review. Nothing is published without you. | Beta | [waitlist](https://gentbajko.dev/#clippa) |

Capstone and Quarry are meant to be run together — [archways.dev](https://archways.dev).
